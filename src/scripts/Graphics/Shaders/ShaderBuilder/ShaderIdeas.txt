 There are 2 main implementations for creating effects via fragment shaders for apps meshes.

1. Use the vertices and the vertex shader of the original mesh, and by calling a function in the fragment shader create the effect.
   The downside is that the effect can be created inside the mesh dimentions.
2. Use the original mesh to create a secondary mesh, with different dimentions, and render the effect to that new meshes.
   In this case we can draw the effect to the new dimentions, but we need to set up the mesh creation and the shaders,
   as a separate functionality.
