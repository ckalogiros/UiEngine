Scissor testing can leak between draw calls File: src/scripts/Graphics/GlDraw.js, lines 60–63 Confirmed state-management defect The draw loop enables gl.SCISSOR_TEST when a vertex-buffer group has a scissor box, but the inspected code doesn't disable it when subsequent groups don't have one. GitHub js if (vb_group.has_scissorbox) { gl.enable(gl.SCISSOR_TEST); gl.scissor( vb_group.scissorbox[0], vb_group.scissorbox[1], vb_group.scissorbox[2], vb_group.scissorbox[3] ); } Why it matters: WebGL retains this state across draw calls. If a clipped UI element is followed by an ordinary mesh, that mesh can remain clipped to the previous rectangle. Fix: Explicitly set the state for every draw group. js if (vb_group.has_scissorbox) { gl.enable(gl.SCISSOR_TEST); gl.scissor(...vb_group.scissorbox); } else { gl.disable(gl.SCISSOR_TEST); } Adapt the scissor() arguments to the existing four-element array, as in your current implementation. If the engine later adds a state cache, make sure it also tracks the scissor-enabled state. 2. Sampler uniforms can become incorrect when switching programs File: src/scripts/Graphics/GlDraw.js, lines 40–43 and 65–70 Conditional rendering bug The engine sets the sampler uniform only when the texture index changes: js if (GL_STATE.BOUND_TEXTURE_IDX !== vb_group.texidx && vb_group.texidx !== INT_NULL) { const texture = Texture_get_texture_unit_byidx(vb_group.texidx); Gl_texture_unit_bind(gl, texture); gl.uniform1i( progs.buffer[progidx].shaderinfo.uniforms.sampler, texture.texidx ); } But sampler uniforms belong to individual shader programs. Switching to another program doesn't automatically copy the sampler value from the previous program. GitHub Example failure: Program A uses texture unit 3. Inside Vertex_buffer_remove_geometry(), the code iterates over the vertex buffers belonging to a group, but retrieves the buffer info and backing data using gfx.vb.groupidx: js const vb_info = _vertex_buffer_infos.buffer[gfx.vb.groupidx]; // ... const vb_data = _vertex_buffers_data.buffer[gfx.vb.groupidx]; The group index and vertex-buffer index are separate identifiers. GitHub Why it matters: Removing geometry from a group whose index differs from its underlying buffer index can shift the wrong CPU-side data and update the wrong buffer metadata. Full buffer uploads for small geometry changes In src/scripts/Graphics/GlDraw.js, lines 73–90, a dirty vertex buffer is uploaded using gl.bufferData() with the entire CPU-side typed array. Recommended improvement: Track dirty ranges and use gl.bufferSubData() for small updates.
